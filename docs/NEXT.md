# 추가 취재 포인트 · 후속 작업

## 즉시 (단일 케이스 보강)

### 1. DB김준기 89억 매각 거래 — 주무관청 허가 적정성
출연가 3413원 vs 매각가 1030원의 격차 정당성. 서울교육청 기본재산 처분 허가 과정 자료 청구.

### 2. DL 「통일과나눔→KCGI」 우회 경로의 후속
2016~2019 거래 흐름 재구성. 에코그란데(19.0%)와 중진공(7.6%)의 현재 지분 처리. 같은 패턴 다른 그룹 사례 추적.

### 3. SM 필의료재단 — 사업비 0원과 1675억 주식 기부의 시간 일치
정관상 강서필병원 운영 사업 실제 수행 여부. 일반관리비 분류의 적정성. 김혜란 상속분이 재단으로 우회한 자금 흐름.

### 4. LG 상속회복청구 소송 1심·2심·3심 결과와 공익법인 4% 향방
김영식 등 승소 시 공익법인 4%가 캐스팅보트로 등장. 매입 주체 시나리오 별 지배구조 변화 시뮬레이션.

### 5. 사업비 비율 하위 17개 그룹 — 개별 재단 결산서 자금 흐름 추적
「수입은 들어오는데 사업에 안 쓴 돈」이 어디 보유 자산(예금·주식·부동산)으로 귀결됐는지. 국세청 공시 결산서 직접 분석.

### 6. 분배비용 12% vs 인건·관리비 77% 구조의 다른 영역 비교
학술·장학·문화 영역 공익법인의 일반 비율인지, 대기업 공익법인 특이 패턴인지. 정부·민간 공익법인 표본 비교.

## 중기 (데이터 보강)

### 7. CEO스코어 73개 그룹 전수 데이터
현재 27개 그룹(하위 17 + 상위 10) + 「46개 그룹 50~99%」로만 표시. CEO스코어에 직접 요청 또는 보도 기사 추적해 전수 수치 확보.

### 8. 5대 그룹 산하 공익법인 결산서 직접 fetch
국세청 공익법인 공시시스템(`npoinfo.hometax.go.kr`) Playwright 크롤러. 삼성 13개·SK 25개·HD현대 11개 등 핵심 그룹 우선.

### 9. 그룹×재단×보유계열사 네트워크 그래프
현재 텍스트 매트릭스로 23행. D3.js 또는 Cytoscape로 노드-엣지 그래프 시각화. 「공익법인 거미줄」 구조 한눈에.

### 10. 의결권 행사 이력 시계열
공정위가 매년 발표하는 「공익법인 의결권 행사현황」 자료를 연 단위로 누적. 행사 횟수·찬반 추이.
