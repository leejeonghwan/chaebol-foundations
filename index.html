Case Deep Dives

개별 그룹 의혹 구조를 5개 카테고리(승계·탈세·일감몰아주기·사익편취 우회·자금 사용)로 풀어낸 케이스 페이지.

CASE 01

「1조원 사회환원」 18년 + 2022.1 SPC 거래로 정의선 지분 20% 정렬
CASE 02
SM 필의료재단
「5%룰 우회」 교과서 — 김혜란 별세 6개월 안 4단계 동시 진행
CASE 03
DL 통일과나눔
2,868억 출연 → KCGI 1,200억 매각 (장부가 1/4). 우회 매각의 가장 노골적 사례
CASE 04
삼성 4개 재단
의결권 단계 축소(2023~2026) + 삼성생명법 + 웰스토리 — 진행형 「제도 자체」
CASE 05
CJ 3단 우회 승계
씨앤아이→타임와이즈→올리브영. 「재단 아닌 개인회사」가 승계 도구
CASE 06
DB 두 재단
공식 재단 89억 매각 + 동곡사회복지재단 15년 사익 전용. 「공식+그림자」 결합
CASE 07
LG 상속분쟁
2026.2 1심 구광모 승소 → 항소심 진행. 재단 4% 의결권 캐스팅보트 시나리오
CASE 08
SK 25개 재단의 모순
최다 25개 + ESG 1위 vs 행복전통마을 0원·최기원 「유관」·이혼 파기환송
CASE 09
롯데 형제의 난+박근혜 뇌물
신영자 면세점 비리·신동빈 K스포츠 70억·의결권 100% 상실. 사법 처리 가장 누적
CASE 10
카카오 5조 약속 + 시세조종
김범수 5조 사회환원 약속(2021) — 4년 누적 0.4%. 동시에 SM 시세조종으로 2024.7 구속 → 보석
